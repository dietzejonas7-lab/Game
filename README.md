# 🫧 Squishy World

Ein Handyspiel zum Sammeln und Spielen mit realistischen Squishys – mit Soft-Body-Physik,
Echtzeit-Sounds, Lootboxen, Spielerlevel, Sammlungen, Quests und täglichen Belohnungen.

**👉 Alles Wichtige steht in der [ANLEITUNG.md](ANLEITUNG.md)** (Schritt für Schritt, auch ohne Vorkenntnisse).

## Kurz-Befehle

```bash
npm install            # einmalig: benötigte Pakete laden
npm run dev            # Spiel im Browser starten (mit Live-Neuladen)
npm run check:content  # content.json auf Fehler prüfen
npm run build          # fertige Version bauen
npm run android:sync   # Web-Teil in das Android-Projekt kopieren
```

- Inhalte (Squishys, Boxen, Quests, Shop, Events): `public/content/content.json`
- Vorschau aller Squishys: Spiel im Browser öffnen und `#galerie` an die Adresse hängen
